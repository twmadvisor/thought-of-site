SMS Verification

Thought Of authentication messaging

Thought Of uses automated SMS solely to verify a person's own phone number when that person requests a login or account-verification code.

Use case

One-time-password authentication for the Thought Of mobile application.

Example message

Thought Of: Your verification code is 123456. Do not share this code.

How a user opts in

The user opens Thought Of, enters their own mobile phone number into the phone-number login screen, and deliberately taps Send code. No verification SMS is sent until that action is taken.

For the people you think about between conversations.

By tapping Send code, you request a one-time SMS verification code. Message and data rates may apply. We never import your contacts.

Message frequency and opt-out

Message frequency varies and depends on how often the user requests authentication. Message and data rates may apply. Reply STOP to stop SMS messages or HELP for help. A user who opts out may be unable to authenticate by SMS until messaging is re-enabled.

Invitations

Thought Of does not automatically send SMS invitations to third parties. If a user wants to invite someone, the app may open the user's own messaging application with suggested invite text. The user then independently decides whether to send that personal message.

Privacy: Thought Of never imports a user's contacts. See the Privacy Policy for more information.
